# Profuse Beauty research report

This folder contains the professional report prepared from the 14-page Profuse Beauty marketing research dossier.

| File | Purpose |
| --- | --- |
| `profuse-beauty-marketing-research-report.md` | Editable source text. Update this first when findings change. |
| `profuse-beauty-marketing-research-report.html` | Branded, print-ready source using the happyhunterdigital document system. |
| `profuse-beauty-marketing-research-report.pdf` | Ten-page A4 print deliverable. |
| `profuse-beauty-marketing-research-report.docx` | Editable Word version with real heading styles and a live page field. |
| `previews/` | Ten PNG page previews at final A4 trim size. |
| `system.css`, `fonts/`, `assets/` | Self-hosted Inter font, document styles and official logo used by the HTML. |

The report is marked **Confidential client working document** because it includes unpublished commercial gaps, unresolved compliance items and website-risk findings. Sanitise before external distribution.

To view or print, open the HTML in a browser and use **Print / Save PDF** at A4 with no margins and background graphics enabled. No third-party scripts or external assets are loaded.
